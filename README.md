# Учебный проект: Мини-учёт оборудования на 1С

Этот проект создан для демонстрации навыков разработки на платформе **1С:Предприятие 8.3**. 
Он имитирует базовый бизнес-сценарий: поступление оборудования на склад и получение отчёта об остатках.

## 🛠️ Реализованный функционал:
- **Справочники:** «Оборудование» (с реквизитами: модель, производитель, статус) и «Склады».
- **Документ:** «Поступление оборудования» с табличной частью. Реализована логика проведения (движения по регистру накопления).
- **Регистр накопления:** «Остатки оборудования» (учёт по складам и номенклатуре).
- **Отчёт:** Внешний отчёт на СКД, выводящий остатки оборудования на выбранную дату с группировкой по складам.

## 💡 Чему я научился в процессе:
- Работа с деревом метаданных и создание объектов.
- Написание кода в модуле объекта документа (`ОбработкаПроведения`).
- Работа с виртуальными таблицами регистров накопления при написании запроса.
- Настройка СКД для визуализации данных.

## 🚀 Как запустить:
1. Скачайте исходники из репозитория.
2. В Конфигураторе создайте пустую базу.
3. Выберите **«Конфигурация» → «Загрузить конфигурацию из файлов...»** и укажите папку `src`.
